# Gravit × Sygnum Bank – Proof of Concept

**Epistemic Verification for AI‑Agent Transactions in Regulated Banking**

Dieser PoC zeigt, wie Gravit als Trust Layer für die AI‑Agenten von Sygnum Bank fungiert – mit vollständiger FINMA‑Konformität.

## Kernfunktionen

- ✅ **MCP‑Adapter** – Simulation der Schnittstelle zu Sygnums Model Context Protocol
- ✅ **Epistemische Verifikation** – Jede AI‑Transaktion wird vor der Signatur geprüft
- ✅ **FINMA‑Audit Trail** – Generierung kryptografischer Beweise für Regulierer
- ✅ **Token‑Unterstützung** – dCHF, Equity‑Tokens, NFTs (basierend auf ihren öffentlichen Contracts)
